## Описание проекта

Legendary Age — прототип онлайн-RPG с воксельной стилистикой. Игрок подключается к серверу через лаунчер, регистрирует аккаунт, создаёт героя, выбирает его пол, класс и причёску, после чего может запустить игру в доступном на устройстве режиме: облегчённом 2D или трёхмерном WebGL.

Игровой мир состоит из трёх связанных локаций: Стартового Города, Лесного Туннеля и Мрачного Подземелья. Карта и декорации формируются детерминированно, поэтому 2D- и 3D-клиенты отображают одинаковое окружение. В опасных зонах встречаются слизни, орки, скелеты и летучие мыши.

Проект включает систему аккаунтов и персонажей, несколько игровых классов, перемещение между локациями, сражения с противниками, здоровье и опыт, сетевую синхронизацию игроков и игровой чат. Персонажи, монстры и окружение собираются из процедурных воксельных моделей, а лёгкий шум яркости добавляет поверхностям фактуру.

## Основные возможности

- регистрация и вход в аккаунт;
- создание и настройка персонажа;
- выбор класса героя;
- отдельные 2D- и 3D-режимы;
- общий процедурно сформированный мир для обоих режимов;
- три игровые локации с переходами между ними;
- противники и базовая боевая система;
- здоровье, опыт и развитие персонажа;
- сетевой мультиплеер и чат;
- запуск локального сервера;
- сборка портативного приложения для Windows.

## Технологии

Клиент и лаунчер написаны на HTML, CSS и JavaScript и запускаются в Electron. Трёхмерная графика реализована с помощью Three.js, а сетевой обмен — через WebSocket с библиотекой `ws`. Серверная часть работает на Node.js.

## Структура проекта

- `index.html` — лаунчер, авторизация, создание и настройка персонажа;
- `game.html` — основной игровой клиент и интерфейс;
- `main.js` — запуск Electron-приложения и локального сервера;
- `server.js` — многопользовательский сервер;
- `world.js` — локации, генерация земли, декорации и препятствия;
- `voxel-db.js` — параметры внешности и классов, сборка модели персонажа;
- `voxel-models.js` — модели персонажей, монстров и окружения;
- `voxel2d.js` — 2D-отрисовка воксельных моделей;
- `package.json` — зависимости, команды запуска и параметры сборки.

## Требования

Для разработки необходимы Node.js и npm. Для трёхмерного режима требуется видеокарта и браузерный движок с поддержкой WebGL. 2D-режим рассчитан на менее производительные компьютеры.

## Установка и запуск

Установите зависимости:

```bash
npm install
```

Запустите сервер игры на порту `8080`:

```bash
npm run server
```

В другом окне терминала запустите лаунчер:

```bash
npm start
```

В лаунчере укажите адрес сервера:

```text
ws://localhost:8080
```

Для одновременного запуска лаунчера и локального сервера используйте:

```bash
npm run start:local
```

## Сборка для Windows

Создание портативного исполняемого файла:

```bash
npm run build
```

Результат сборки:

```text
dist/Legendary Age 0.2.0.exe
```

Запуск приложения вместе с сервером:

```text
"Legendary Age 0.2.0.exe" --server
```

Запуск только сервера:

```text
"Legendary Age 0.2.0.exe" --server-only
```

## Примечание

Проект находится в стадии прототипа. Перед публичным размещением рекомендуется отдельно проверить безопасность хранения учётных данных, обработку входящих WebSocket-сообщений, резервное копирование игровых данных и устойчивость сервера к некорректным запросам.

# Описание проекта Legendary Age

Legendary Age — многопользовательская ролевая игра в воксельной стилистике с двумя вариантами отображения игрового мира. Облегчённый 2D-режим подходит для большинства компьютеров, а 3D-режим использует WebGL и предназначен для устройств с совместимой видеокартой.

Игрок создаёт аккаунт и персонажа, выбирает класс и внешность, исследует три связанные локации, сражается с монстрами и получает опыт. Через WebSocket-сервер синхронизируются подключённые игроки и сообщения чата. Процедурные модели и детерминированная генерация мира обеспечивают единое содержимое в 2D- и 3D-клиентах.

Проект создан на JavaScript, Node.js и Electron. Для трёхмерной графики применяется Three.js, для сетевого взаимодействия — библиотека ws. Репозиторий содержит лаунчер, игровой клиент, сервер, описание мира, базу параметров персонажей и систему воксельного рендеринга.

Подробные инструкции по установке, запуску, структуре файлов и сборке находятся в `README.md`.
